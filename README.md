# 🎨 color_key

**Текст ↔ Цвета ↔ CSS-картина**

Офлайн-инструмент для кодирования любой текстовой информации в HEX-цвета и генерации абстрактной CSS-картины в стиле Кандинского. Цвета можно сохранять, печатать, публиковать — и расшифровывать обратно в текст даже если порядок цветов перепутан.

## 🧠 Как это работает

`Текст → UTF-8 байты → HEX-строка → блоки по 6 символов → индекс-префикс (00, 02, 04...) → HEX-цвет → CSS-картина`

Каждый блок данных дополняется индексом порядка — первые 2 символа HEX-кода кодируют позицию. Это позволяет **перемешивать цвета как угодно** — при расшифровке порядок восстанавливается автоматически.

---

## 🚀 Возможности

- ✅ **Текст → цвета** — любой текст превращается в палитру HEX-кодов с индексами
- ✅ **Цвета → текст** — обратное декодирование с автосортировкой
- 🔀 **Перемешивание** — демонстрация: цвета путаются, расшифровка всё равно работает
- 🖼️ **CSS-картина** — генерация абстрактной картины в стиле Кандинского из ваших цветов
- 🔍 **Парсинг CSS** — вставьте весь HTML/CSS-код картины — скрипт сам найдёт цвета в `title="#..."` и расшифрует
- 💾 **Сохранение** — картина сохраняется как отдельный HTML-файл
- 📋 **Копирование** — HEX-коды и CSS картины в один клик
- 📴 **Полный офлайн** — никакие данные не отправляются в сеть

## 🎯 Пример использования

### Кодирование
1. Введите текст: `Ячейка 731, код 90210`
2. Нажмите **«Закодировать»**
3. Получите палитру цветов и список HEX-кодов

### CSS-картина
1. После кодирования нажмите **«Создать CSS-картину»**
2. Сохраните как HTML-файл или скопируйте CSS
3. Картину можно распечатать, повесить на стену, вставить в сайт

### Расшифровка (даже без знания порядка)
1. Вставьте HEX-коды (или весь CSS картины) в поле расшифровки
2. Нажмите **«Расшифровать»**
3. Скрипт сам найдёт цвета, отсортирует по индексам и восстановит текст

### Проверка автосортировки
1. Закодируйте текст
2. Нажмите **«Перемешать»** — цвета перепутаются
3. Нажмите **«Расшифровать»** — получите исходный текст

## 🔐 Безопасность

- **Индексы внутри цветов** — порядок не важен, восстанавливается автоматически
- **Без индексов** — перебор `n!` вариантов, где n — количество цветов
- **16 цветов** = 16! ≈ 2 × 10¹³ комбинаций
- **Рекомендуется** использовать на отключённом от сети компьютере для максимальной безопасности
